# 早上对着 AI 聊天发懵，下午我给它们做了张小纸条



---


我用 Agent 干活有一段时间了，用着确实挺顺手的，会话开的越来越多。第二天早上，我打开电脑，看着列表里面的很多会话，有点发懵，不知所措。

哪个是昨天干的来着？昨天干到哪了？这个摘要写的这个名字，我咋一点印象都没有？

点进去翻吧。从头翻到尾，哦，想起来了。退出来换下一个，又忘了。就这么一个一个翻完，一上午过去了，活还没开始干。

我坐在那想了想，觉得这样下去不行。但是又说不上来哪里不行。

是会话开太多了吗？好像是，好像又不是。

我这人有个习惯，遇到问题先找现成的，能不动手就不动手。这毛病肯定不止我一个人有，我就觉得，这种事早就有人把方案做好了吧。

我去问 GPT，它挺热心，给我推荐了好几个管理工具。我挨个看了看，看着看着就蔫了。

那些工具，大多是给写代码的程序员做的。思路是把事情拆成一条一条的任务，列在那，做完一条划掉一条。听着挺利索。但是我对照了一下自己的活，对不上。

我的工作是来一个干一个，每个都不一样。而且每个活干起来之前，根本没有一份完整的大纲，告诉你它最后会长成什么样子。都是干着干着，研究着研究着，才慢慢想清楚的。方向还会变，今天觉得该这么做，明天材料一看，得，换一条路。

你说这种活，怎么提前列任务清单呢？列出来的一半都得作废，作废了你还得花功夫去删、去重新排。管理清单本身，又变成了一份新工作。

想到这里我有点泄气。原来不是我的问题怪，是我这类工作，压根没人照着做工具。

那段时间我没事就拉着 GPT 聊这个事。现在回头看，那几天其实就干了一件事，把问题越聊越小。

一开始我以为，问题是会话太多。聊着聊着发现不对，多不多其实无所谓，问题是它们不告诉我，自己停在哪了。就像办公桌上堆了一摞文件，堆多少不重要，重要的是每份文件上都该贴个条，写着办到哪了。

然后我又以为，得给每个会话配一份任务清单。就是上面说的那个思路，很快被我自己否了。

聊到这，GPT 提了一件事。它说，其实 AI 自己有个习惯，会话聊得太长了，它怕记不住前面的内容，就会把之前的对话压缩成一份总结，存起来自己看。行话叫压缩，你可以理解成，AI 在给自己写小抄。

我听到这，灵机一动。

诶，它写完的小抄，是不是就是我想要的东西？我直接拿来用，不就完了吗？

当时我挺高兴，觉得这事要成了，捡了个现成的。

结果翻开小抄一看，心凉了半截。

那个小抄，是写给 AI 自己看的。密密麻麻，全是代码味，什么目标、上下文、关键决策，排得整整齐齐，但是人看着费劲。更麻烦的是它还懒，只有会话聊到特别长的时候它才写。聊得短的会话，人家根本不写。而我想知道状态的，恰恰是那些不长不短的。

现成的指望不上了。

那咋办，自己动手呗。

这里得交代一下背景。我用的这个 Agent 软件叫 HanaAgent，是个开源的玩意，好处是里面的东西都能翻开看。陪着我干活的，是我自己捏的一个助手，叫 Hanako。

那天早上发完懵，中午我就坐不住了，想把这事解决掉。

Hanako 先去翻了一遍软件的储藏室，翻出来三样东西。

第一样，会话的完整记录。原来每个会话说过的每句话，软件都老老实实存在一个文件里，一句没丢。

第二样，一个会敲铃的地方。每说完一段话，软件内部就会敲一下铃，通知一声，这段说完了。

第三样，软件自带的 AI 能力。就在那摆着，不用白不用。

这三样拼在一起，路子就出来了。每说完一段话，铃一响，就让 AI 把这个会话到目前为止干了啥，攒成一份小档案，存在本地。

那小档案里写什么呢？这个问题根本不用现想。之前和 GPT 聊的时候，我列过几个问题，一个会话为啥开的，中间干了啥，干出了啥，现在停在哪，接下来可能要干啥。

这五个问题，原样变成了档案的五个格子。

我看到的时候愣了一下。聊了那么久的东西，真的长出来了。

档案能自动写了，我本以为最难的已经过去了。

结果最难的才刚来。

我想让这份档案挂在侧边栏，我看哪个会话，它就显示哪个会话的档案。听着挺简单对吧。

问题是，侧边栏那个小窗格，和中间的主界面，其实是两个房间，中间隔着一堵墙。小窗格看不见你正在看哪个会话，只能干瞪眼。

我们想了好几个办法，全堵死了。问软件吧，软件没留这个问话的口子。想从墙缝里瞄一眼吧，又被拦住了，说不许看。

最后没辙，我们往墙那边装了个小侦探。它啥也不干，就蹲在那盯着主界面，一发现你换了会话，就朝小窗格喊一嗓子。

通了。

看着侧边栏跟着我点的会话，一下一下换过去，我在电脑前坐了好几秒。那种感觉咋说呢，就像你折腾了一天的东西，终于活过来了。

能用了，但是丑。灰扑扑的，像个半成品。

我这人对界面好不好看有点执念，就去找 Kimi 帮忙设计。做的是 Claude 那种风格，大家经常能看到的那种，暖色的，像纸一样。

不得不说，K3 的设计审美真的挺在线。颜色很克制，干干净净的，会话的状态用一个小圆灯表示，一眼就知道这个会话是还在干，还是搁置了，还是已经做完了。

最后一步，打包，起名字，传到 GitHub 上。给同样有这个毛病的同好用。

从早上发懵，到东西上线，一天。

第二天早上，我又打开电脑。

还是那排会话，还是一个挨一个的名字。但这次不一样了。我点到哪个，侧边栏就轻轻跟着换到哪个。每个会话为啥开的，停在哪，接下来可能要干啥，安安静静写在上面。

我坐那看了一会儿，心里挺踏实的。

那种发懵的早晨，以后应该不会再有了。

后来我又想，这一天里最花时间的，其实不是做东西，是把一个说不清道不明的不适，一点一点说清楚。从有点发懵，到看不见状态，到会话不是任务，再到那五个格子。

想清楚了，东西自己就会做了。

大概很多事情都是这样吧。
